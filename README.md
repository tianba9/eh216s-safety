# 亿航 EH216-S 全方位安全分析

按系统安全工程八步法，对 EH216-S 做危害识别、架构论证、软硬件安全设计与运行安全论证。

在线阅读：https://tianba9.github.io/eh216s-safety/

## 五条安全结论

1. **取消驾驶员是全机安全架构的第一性选择。** 消除人因失效，同时取消机上最后兜底，责任转移到自动化与地面。
2. **三余度解决随机失效，解决不了共因失效。** 若三套飞控同源，2oo3 在软件缺陷前退化为 1oo1。
3. **九万架次是运行证据，不是 10⁻⁹ 的统计证明。** 累计约 3.75 万飞行小时，距统计效力差约四个数量级。
4. **最严重的危害是空中失控、能源失效、坠撞保护，其中被动安全证据最弱。**
5. **剩余风险主要在运行边界，不在硬件。** 气象、空域、人群隔离、远程机组人因，靠 ODD 而非冗余控制。

本报告自定义评级：**R2 限定场景放行**，依据见第 08 章。

## 两个专题的定量结论

- **飞控冗余**：按每副旋翼 500 N 估算，单副与单臂失效后仍有总推力余量，损失两臂后余量约 −1.4%。姿态控制和安全迫降需独立验证。
- **坠撞安全**：按 20 g 平均减速度估算，8 m/s 和 12 m/s 分别需要约 0.16 m 和 0.37 m 理论吸能行程。实际可用行程和乘员伤害判据需另行验证。

## 方法边界

本报告为**第三方独立复算**：未获得厂商的 FHA/PSSA/SSA/FMEA 与符合性验证文件，全部分析基于公开信息重建。故障树给出割集与定性排序，不给出顶事件概率。凡未公开的配置（整机降落伞、机载灭火、供电拓扑、软件是否异构），一律标注「未披露」，不推断为「没有」。
