## 核心结论

1. 取消驾驶员是全机安全架构的第一性选择，责任转移到自动化与地面。
2. 三余度解决随机失效，解决不了共因失效；CCA 是真正的考验。
3. 九万架次是运行证据，不是 10⁻⁹ 的统计证明。
4. 最严重的危害是空中失控、能源失效、坠撞保护，其中被动安全证据最弱。
5. 剩余风险主要在运行边界，而非硬件。

## 两个专题的定量结论

- **飞控冗余**：按每副旋翼最大推力 500 N 估算，可容忍单副与单臂失效；损失两臂（4 副）后推力余量转负，容错边界在「两臂」附近。
- **坠撞安全**：8 m/s 垂直撞击需约 0.3 m 吸能行程才能把减速度压到人体耐受范围内；12 m/s 时任何行程均超限，只能靠避免撞地。
